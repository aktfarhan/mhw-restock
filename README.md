# MHW Restock Mod

Restock your item pouch with a keybind in Monster Hunter: World.

When you press the key in a base, the mod applies one of your saved item loadouts.

## Requirements

- Stracker's Loader (4.0)

## Install

1. Download the latest zip from [Releases](https://github.com/aktfarhan/mhw-restock/releases).
2. Copy `mhw_restock.dll` into your game folder at `Monster Hunter World\nativePC\plugins\`.

## Use

While in base, press F5. Your pouch will be restocked with item loadout 1.

## Settings

You can change the keybind and the saved loadout in the .ini file.

```ini
[Settings]
Key=F5
Loadout=1
```

| Setting   | Values                       |
| --------- | ---------------------------- |
| `Key`     | `A`–`Z`, `0`–`9`, `F1`–`F12` |
| `Loadout` | `1`–`80`                     |
